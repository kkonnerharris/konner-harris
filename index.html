    pull request · NVIDIA · OpenUSD
    Stage start and end frame sample
    PR #83 (closes issue #12): NVIDIA's OpenUSD Code Samples had no example of setting a stage's frame range. Added one in Python and USDA using SetStartTimeCode and SetEndTimeCode, with docs covering the defaults (0, and 24 time codes per second) and the edit-target rule I confirmed against usd-core 25.11. Asserts that fail if a setter is removed, and a clean docs build.
    NVIDIA-Omniverse/OpenUSD-Code-Samples#83 ↗
    
          
    pull request · Netflix · metaflow-ui
    Default time filter read in base 30
    PR #210: MF_DEFAULT_TIME_FILTER_DAYS was parsed with parseInt(value, 30), a radix of 30 instead of 10, so 14 days became 34 and the documented default of 30 became 90. Parsed it in base 10, fell back to the 30-day default for anything that isn't a positive number of days, and added Cypress tests that fail on the old code. Checked in a browser: 14 now gives 14 days.
    Netflix/metaflow-ui#210 ↗
    
          
    pull request · Netflix · metaflow-ui
    README: deploy links and an undocumented setting
    PR #211: the "Metaflow UI Service" links went to the root of the service repo instead of the folder with the deploy steps, the Docker image's MF_DEFAULT_TIME_FILTER_DAYS setting wasn't documented, and the meta-tag example wasn't a command you could run. Repointed the links to services/ui_backend_service, documented the setting with an example, rewrote the example as a full docker run, and turned bare URLs into links. Kept clear of two other open README PRs to avoid merge conflicts.
    Netflix/metaflow-ui#211 ↗
